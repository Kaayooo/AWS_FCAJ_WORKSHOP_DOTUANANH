During my internship at **[Amazon Web Services Viet Nam Company Limited]** from **[06/22/2026]** to **[08/15/2026]**, I had the opportunity to learn, practice, and apply the knowledge acquired in school to a real-world working environment.  

I participated in building a Serverless Data Lake system as part of the First Cloud AI Journey program. I was directly responsible for designing and deploying an automated ETL pipeline on AWS to collect and standardize stock trading and market news data. The work ranged from setting up the storage layer with Amazon S3, processing data via AWS Glue and AWS Lambda, querying with Amazon Athena, to orchestrating the workflow using EventBridge and Step Functions. In addition, the system integrated a user interface layer using AWS Amplify, API management and authentication via API Gateway and Amazon Cognito, as well as a notification service through Amazon SES. This significantly improved my skills in operating, integrating, and optimizing costs for serverless services on AWS. This process helped solidify my analytical, design, and architectural layering mindset using Draw.io. Concurrently, I enhanced my ability to deploy cloud infrastructure, write technical reports, work in a team, and proactively monitor and troubleshoot issues in a real-world environment.  

In terms of work ethic, I always strived to complete tasks well, complied with workplace regulations, and actively engaged with colleagues to improve work efficiency.
