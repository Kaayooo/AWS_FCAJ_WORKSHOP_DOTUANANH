### Kết quả đạt được tuần 3:

* Họp team định hình ý tưởng project, khảo sát nguồn dữ liệu, lựa chọn công nghệ/dịch vụ AWS và hoàn thành report chốt hướng phát triển.

* Nghiên cứu tổng quan về Data Lake để tích hợp vào project.
* Tìm hiểu chi tiết các thành phần của hệ sinh thái AWS Glue:
  * AWS Glue
  * AWS Glue ETL
  * AWS Glue Data Catalog
  * AWS Glue Crawler
