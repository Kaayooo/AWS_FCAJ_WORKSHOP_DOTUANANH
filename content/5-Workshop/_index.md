# Build a Serverless Financial Distress Prediction Platform on AWS

#### Overview

This workshop is derived from the project proposal and weekly worklog entries for the Vietnam Financial Distress Prediction System. It guides you through the main AWS services and implementation steps used in the project: data ingestion, storage, ETL, machine learning, dashboard deployment, and alerting.

The lab is designed to help you connect the concepts learned during the worklog weeks with a practical end-to-end architecture for an AWS-based financial analytics solution.
